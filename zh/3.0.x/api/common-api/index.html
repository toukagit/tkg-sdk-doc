3 广告接入​

3.1 插屏广告​

APIParameterDescription
ShowInterstitialAd(TKGIVAdPositionName _adPos, Action _callback = null, IVADType _IvType = IVADType.IV1)播放插屏广告
_adPos: 插屏广告点位名称（需自行在TKGIVAdPositionName中添加定义）
_callback: 插屏回调。
关闭插屏和插屏未成功播放等都会回给这个回调。
_IvType: 插屏频次控制类型
IsReadyInterstitialAd-判断当前是否存在可展示的插屏广告。
一般游戏无需自行调用。

3.1.1 示例代码​

// show interstitial ad
TKGSDKManager.Instance.ShowInterstitialAd(TKGIVAdPositionName.IV_Retry);

// is ready interstitial ad
bool isReadyIV = TKGSDKManager.Instance.IsReadyInterstitialAd();

3.2 激励视频广告​

APIParameterDescription
ShowRewardAd(TKGRVPositionName _adPos, Action<bool> _rewardCallback = null, Action _showFailedCallback = null, bool _showSDKToast = false)播放激励视频广告
_adPos: 激励视频广告点位名称（需自行在TKGRVPositionName中添加定义）
_rewardCallback: 激励视频奖励回调。(在此回调中处理下发奖励)
_showFailedCallback: 激励视频未成功播放回调
_showSDKToast: 是否使用SDK激励视频展示失败提示页面； true:使用SDK提供的失败提示页面;
false:不使用SDK提供的失败提示页面

IsReadyRewardAd-判断当前是否存在可展示的激励视频广告。
一般游戏无需自行调用。

3.1.1 示例代码​

// show reward ad
TKGSDKManager.Instance.ShowRewardAd(TKGRVPositionName.RV_GetDoubleCoin, RewardResult);

private void RewardResult(bool _bReward)
{
    Debug.Log("[ToukaSDKDemo] Reward result：" + _bReward);
}


// is ready reward ad
bool isReadyRV = TKGSDKManager.Instance. IsReadyRewardAd();

3.3 开屏广告​

接入开屏广告无需做任何处理。

3.4 native 广告​

APIParameterDescription
ShowNative(RectTransform pRect, Camera pCam = null, string pAdPos = "")展示原生广告
pRect: 原生广告展示位置
pCam: 如果UI使用相机模式，必须使用正交相机
_pos: 展示native广告点位名称
IsReadyNativeAd-判断当前是否存在可展示的原生广告。
一般游戏无需自行调用。

3.4.1 示例代码​

// show native ad
TKGSDKManager.Instance.ShowNative(nativeImage.rectTransform);


// is ready native ad
bool isReadyNative = TKGSDKManager.Instance.IsReadyNativeAd();

3.5 banner 广告​

APIParameterDescription
ShowBanner(TKGBannerAlign _bannerAlign)展示横幅广告

_bannerAlign: 横幅广告所展示的位置

HideBanner-隐藏banner广告

3.5.1 示例代码​

// show banner ad
TKGSDKManager.Instance.ShowBanner(TKGBannerAlign.BannerCenterBottomAlign);

// hide ad
TKGSDKManager.Instance.HideBanner();

4 事件埋点​

4.1 关卡进度事件​

APIParameterDescription
LevelStart(int _level)
(string _level)		关卡开始事件
_level: 正在进行的关卡序号值
LevelEnd(int _level, StageResult _stageResult)
(string _level, StageResult _stageResult)		关卡结束事件
_level: 正在进行的关卡序号值
_stageResult: 关卡结束结果

StageResult : StageSucc / StageFail / 游戏内重试: StageRetry / 游戏内返回: StageBack

4.1.1 关卡开始事件​

TKGSDKManager.Instance.LevelStart(1);
TKGSDKManager.Instance.LevelStart("S_1");

4.1.2 关卡结束事件​

TKGSDKManager.Instance.LevelEnd(1, StageResult.StageSucc);
TKGSDKManager.Instance.LevelEnd("S_1", StageResult.StageFail);
TKGSDKManager.Instance.LevelEnd(3, StageResult.StageRetry);
TKGSDKManager.Instance.LevelEnd("S_2", StageResult.StageBack);

4.2 自定义事件​

APIParameterDescription
LogEvent(string _eventSort) 上报游戏埋点事件（参数个数不同）
LogEvent(string _eventSort, string _key, string _value) 同上
LogEvent(string _eventSort, string _key01, string _value01, string _key02, string _value02) 同上
LogEvent(string _eventSort, Dictionary<string, string> _eventDic = null) 同上

4.2.1 示例代码​

TKGSDKManager.Instance.LogEvent("click_Skin");
TKGSDKManager.Instance.LogEvent("get_gift", "stage_level", "1");
TKGSDKManager.Instance.LogEvent("stage_end", "stage_level", "1", "stage_status", "success");

5 内购 (v3.0.4新增)​

5.1 宏定义：​

添加宏定义： USE_IAP

5.2 商品ID：​

在IAPProducts.cs 文件中添加商品ID

public const string NoAds = "test.tremoveads";

public static readonly Dictionary<string, ProductType> ProductDic = new Dictionary<string, ProductType>()
{
    // ProductType.NonConsumable  只能购买一次。适合一次性购买的商品，如额外的关卡
    // ProductType.Consumable     可以反复购买。适合虚拟货币等可消耗商品
    // ProductType.Subscription   可以反复购买和恢复。耐用品，但有效期有限（订阅）
    
    { NoAds, ProductType.NonConsumable}
        
};

5.3 内购回调​


IAPTool.Instance.OnPurchaseDone += OnPurchaseResult;
private void OnPurchaseResult(string pID, bool pResult)
{
    if (pID.Equals(IAPProducts.NoAds) && pResult)
    {
        // 内购成功后，去除广告
        TKGSDKManager.Instance.IsRemoveAds = true;
    }
}

5.4 内购接口​

IAPTool.Instance.BuyProductByID(IAPProducts.NoAds);

APIParameterDescription
LogIAPBtnShow(string _iap,

string _currency,
string _price)		内购按钮展示
_iap : 游戏侧自定义商品名称

_currency : 货币单位,如：USD
_price : 购买价格
LogIAPBtnClick(string _iap,
string _id,
string _currency,
string _price)		内购按钮点击
（参数同上）
LogIAPFirstPurchase(string _iap,
string _id,
string _currency,
string _price)		首次购买成功
（参数同上）

string _id,
string _gameOrderid,
string _paymentChannelOrderid,
string _productToken,
string _paymentMethod,
string _currency,

_id : 商品ID
_gameOrderid : 游戏侧订单ID
_paymentChannelOrderid : 支付渠道订单ID
_productToken : GooglePlay购买令牌，其他支付方式传空
_paymentMethod : 支付渠道：AppStore、GooglePlay
_currency : 货币单位,如：USD

6 账号系统(v3.0.5新增)​

APIParameterDescription
Login (LoginType _loginType, Action<LoginStatus, LoginType, string, string, string, string,string,string> _loginResultCallback)账号登录
_loginType：登录类型 _loginResultCallback：登录回调
Logout (Action _logoutCallback = null)账号登出
_logoutCallback：登出回调
AvailableLoginChannelList -返回当前可用的登录方式
DeleteAccount (Action<DeleteStatus,string> _deleteAccountCallback = null)账号删除
_deleteAccountCallback：账号删除回调，返回被删除的userId及删除状态码
BindAccount (LoginType type, Action<BindAccountStatus, LoginType, string, string, string, string, string, string, string[]> _bindAccountCallback)账号绑定
_loginType：登录类型 _loginResultCallback：绑定回调
ForceBindAccount (string userId,Action<BindAccountStatus, LoginType, string, string, string, string, string, string, string[]> _bindAccountCallback)强制账号绑定
_userId：用户ID _bindAccountCallback：强制绑定回调

6.1 示例代码​


// 账号登录
TKGSDKManager.Instance.Login(LoginType.LOGIN_BY_GOOGLE, (loginStatus,  loginType,  loginMsg,  userId,  token,  email,  nickName,  iconUrl) =>{

    Debug.Log("登录状态码:"+loginStatus);
    Debug.Log("登录类型:" + loginType);
    Debug.Log("登录状态信息:" + loginMsg);
    Debug.Log("用户ID:" + userId);
    Debug.Log("token:" + token);
    Debug.Log("邮箱:" + email);
    Debug.Log("显示名称:" + nickName);
    Debug.Log("头像url:" + iconUrl);
    
});

// 账号登出
TKGSDKManager.Instance.Logout();

// 查询可用的登录方式
List<LoginType> list = TKGSDKManager.Instance.AvailableLoginChannelList();

// 删除当前账号
TKGSDKManager.Instance.DeleteAccount();

// 账号绑定
TKGSDKManager.Instance.BindAccount(LoginType.LOGIN_BY_GOOGLE,(bindAccountStatus,loginType,loginMsg,userId,token,email,nickName,iconUrl,userIdList)=> {

                Debug.Log("绑定状态码:" + bindAccountStatus);
                Debug.Log("登录类型:" + loginType);
                Debug.Log("登录状态信息:" + loginMsg);
                Debug.Log("用户ID:" + userId);
                Debug.Log("token:" + token);
                Debug.Log("邮箱:" + email);
                Debug.Log("显示名称:" + nickName);
                Debug.Log("头像url:" + iconUrl);
                Debug.Log("userId列表："+userIdList);

            });

// 强制账号绑定
TKGSDKManager.Instance.ForceBindAccount("userId001",(bindAccountStatus,loginType,loginMsg,userId,token,email,nickName,iconUrl,userIdList)=> {

                Debug.Log("绑定状态码:" + bindAccountStatus);
                Debug.Log("登录类型:" + loginType);
                Debug.Log("登录状态信息:" + loginMsg);
                Debug.Log("用户ID:" + userId);
                Debug.Log("token:" + token);
                Debug.Log("邮箱:" + email);
                Debug.Log("显示名称:" + nickName);
                Debug.Log("头像url:" + iconUrl);
                Debug.Log("userId列表："+userIdList);

            });
